{% if G.on %}SET UP{% else %}NOT SET UP{% endif %}

The server can look for a newer release of the suite on GitHub and download its update file itself. The download goes through the same checks as an uploaded file: only update files signed for this suite, newer than what's installed, are accepted. This is an internet connection (to github.com), used only when set up here, and it never installs anything by itself.
