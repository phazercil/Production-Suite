How to set up Grafana
  1. In Grafana, add a MySQL data source pointing at the suite's database (the DB_* settings in the server's .env). Use a read-only account.
  2. Make a dashboard with a line variable: SELECT DISTINCT line FROM hmi_ppm. This screen passes var-line and the shift start time, so one dashboard serves every machine.
  3. Speed panel query:
    SELECT t AS time, ppm AS "P/m"
FROM hmi_ppm
WHERE line = '$line' AND $__timeFilter(t)
ORDER BY t
  4. Downtime as annotations (Dashboard settings › Annotations, same data source):
    SELECT start_time AS time, end_time AS timeend,
       CONCAT(reason, ' · ', minutes, ' min') AS text
FROM hmi_downtime
WHERE line = '$line' AND $__timeFilter(start_time)
  5. Other ready-made views: hmi_qc, hmi_shifts, hmi_mo_runs, hmi_tickets, hmi_machine_errors.
  6. Allow embedding in grafana.ini, then restart Grafana:
    [security]
allow_embedding = true

[auth.anonymous]
enabled = true
org_role = Viewer        ; or use your SSO / auth proxy instead
  7. Find panel IDs: open a panel › Share › Embed. The link contains panelId=.
