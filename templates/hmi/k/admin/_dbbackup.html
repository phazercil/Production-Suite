How to restore one {% if DB.engine == "mariadb" %}

Stop the suite, then on a computer with the MariaDB client: gunzip -c production_suite-….sql.gz | mariadb -u root -p {{ DB.name }} (on Windows, unzip it with 7-Zip, then mariadb -u root -p {{ DB.name }} < production_suite-….sql). Start the suite again.
