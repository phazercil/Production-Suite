Each card on the left is a table with a title, the columns you need and the rows it keeps (its filter); press ✎ to set them. A table can have several cards, e.g. one table that logs every machine with a card per machine (machine = Barbara). Drag from a column's dot to the dot of what the suite needs to wire them (or tap a column, then tap the input); the box then reads that card's rows. Click a wire to unwire it. Nothing changes until you press a box's Save.
